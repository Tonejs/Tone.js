Unlike Tone.AmplitudeEnvelope, which has an audio input and applies the envelope directly to a signal passing through it, Tone.Envelope has no audio input — it only outputs a control value from 0 to 1. That makes it useful as a one-shot modulation source: here it's scaled through a Tone.Gain and connected to a filter's cutoff frequency, so each trigger sweeps the filter open and closed — a classic "envelope filter" or "auto-wah" effect.
